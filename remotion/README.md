# remotion/

Planned: Remotion project that renders, from a timed-lyrics JSON + audio:

- 16:9 full-length lyric video
- 9:16 hook clip (15–30 s) for Shorts / Reels
- Thumbnail still

Style presets: kinetic typography, VHS/film grain, paper cutout, minimal one-word,
Pexels b-roll + karaoke, audio-reactive. Tamil fonts: Noto Sans Tamil, Catamaran, Mukta Malar.
Includes channel watermark and platform safe zones.

Licence note: Remotion is free only for teams of up to 3 people.
