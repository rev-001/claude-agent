# dashboard/

Planned: Cloudflare Pages app, protected by Cloudflare Access (owner's email only).

- Song intake form: lyrics, language (Tamil / English / mixed), mood, style hint, or upload of a finished song with its licence
- Job list with live status from the Worker API
- Preview player for the 16:9 full video and 9:16 hook
- Timing-nudge tool to shift lyric lines when Tamil alignment drifts
- Approve / reject buttons (the only way anything gets posted)
- Analytics view

Talks only to the Worker API; holds no secrets.
